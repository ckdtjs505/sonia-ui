AI와 쓰기

sonia-ui는 AI가 읽고 바로 쓰도록 만들었다. 링크 하나를 주면 규칙·설치법·모든 값을 안다.

AI에게 이렇게 말하기

아무 AI 코딩 도구에 붙여 넣는다.

프롬프트
sonia-ui로 만들어줘.
규칙과 사용법: https://ckdtjs505.github.io/sonia-ui/llms-full.txt

AI용 파일

ClassStyles
llms.txt짧은 안내와 링크 (사이트 루트)
llms-full.txt규칙 · 입구 고르기 · 설치 레시피 · 테마별 색 값 · 클래스 전부, 한 파일
AGENTS.mdsonia-ui 저장소를 고치는 AI용 안내 (CLAUDE.md도 같은 파일)
node_modules/sonia-ui/llms-full.txt설치한 프로젝트에서는 로컬 파일로도 읽힌다

설치 없이 두 줄

데모·정적 페이지는 이 두 줄이면 색·컴포넌트·테마 선택까지 된다.

index.html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/ckdtjs505/sonia-ui@1/src/css/base.css">
<script src="https://cdn.jsdelivr.net/gh/ckdtjs505/sonia-ui@1/src/browser/theme.js"></script>

<select data-theme-select></select>
<button class="sn-btn sn-btn-primary">저장</button>

AI가 지키는 규칙

ClassStyles
색역할 이름만 (bg-primary, var(--color-surface)). hex 금지
간격·모서리·글자이름 단계만 (p-lg, rounded-md, text-title)
컴포넌트sn-btn · sn-card · sn-tag · sn-input 조합
다크 모드따로 만들지 않음. data-theme가 해결
값 바꾸기프로젝트에서 덮지 말고 sonia-ui를 고침

Claude Code 스킬

skill/SKILL.md를 ~/.claude/skills/sonia-ui로 연결해 두면, 어느 프로젝트에서든 "sonia-ui로 만들어줘", "테마 붙여줘"에 이 규칙대로 움직인다.

Terminal
ln -s ~/Desktop/web/sonia-ui/skill ~/.claude/skills/sonia-ui
