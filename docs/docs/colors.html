역할

ClassStyles
background화면 바탕
surface카드·시트처럼 떠 있는 면
surface-muted입력창·칩처럼 한 단계 들어간 영역
foreground본문 글자
muted보조 글자
border얇은 구분선
primary강조 · 주요 버튼
primary-soft강조색을 옅게 깐 배경
on-primaryprimary 위의 글자
flame불씨 · 스트릭

예시

<button class="bg-primary text-on-primary ...">저장</button>
<button class="bg-primary-soft text-primary ...">임시 저장</button>
<button class="border border-border text-foreground ...">취소</button>
