테마

모든 테마는 같은 색 이름을 갖고 값만 다르다. data-theme 하나로 화면 전체가 바뀐다.

ClassStyles
data-theme="light"라이트
data-theme="dark"다크
data-theme="nature"숲
data-theme="ocean"바다
data-theme="sunset"노을
data-theme="sepia"세피아
data-theme="ember"잉걸불
data-theme="gold"황금 불꽃
data-theme="sonia"블로그

테마 바꾸기

속성만 바꾸면 된다. 부분에만 다른 테마를 쓰려면 그 요소에 달면 된다.

document.documentElement.dataset.theme = "ocean";

<section data-theme="gold">...</section>
