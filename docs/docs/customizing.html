값 고치기

값은 src/tokens 한 곳에만 있다. 고치고 빌드하면 Tailwind CSS · 앱 테마 · 이 문서가 같이 바뀐다.

1. tokens 고치기

src/tokens/light.ts
// src/tokens/light.ts
spacing: { xs: 4, s: 8, md: 12, lg: 16, ... }

2. 빌드

Terminal
npm run build

src/tailwind/theme.css와 docs/가 다시 만들어진다. 커밋·푸시하면 앱들은 npm i github:ckdtjs505/sonia-ui로 최신을 받는다.

새 테마 추가

// src/tokens/forest.ts
import light, { makeColors } from "./light";

export default { ...light, colors: makeColors({ background: "#0E1A12", ... }), barStyle: "light" };

그다음 src/tokens/index.ts의 themeList와 ThemeId에 추가한다.
