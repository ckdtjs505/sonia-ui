시작하기

설치

Tailwind CSS v4 프로젝트에 sonia-ui 테마를 붙인다. CSS 두 줄이면 끝.

1. 패키지 설치

Terminal
npm i github:ckdtjs505/sonia-ui

2. CSS에 가져오기

Tailwind를 가져온 바로 아래에 sonia-ui/tailwind.css를 가져온다.

app.css
@import "tailwindcss";
@import "sonia-ui/tailwind.css";

3. 테마 고르기

<html>에 data-theme를 단다. 없으면 라이트. 고를 수 있는 값은 테마에.

index.html
<html data-theme="dark">

4. 클래스 쓰기

이제 색·간격·모서리·글자를 이름으로 쓴다.

안녕

sonia-ui로 만든 카드

<div class="rounded-md bg-surface p-lg">
  <p class="text-title">안녕</p>
  <p class="mt-xs text-caption text-muted">sonia-ui로 만든 카드</p>
  <button class="mt-lg rounded-pill bg-primary px-lg py-s text-label text-on-primary">시작</button>
</div>

프레임워크별

Vite: @tailwindcss/vite 플러그인만 켜면 된다. Next.js: next.config에 transpilePackages: ["sonia-ui"]를 넣는다.

글꼴

기본 글꼴은 Pretendard다. <head>에 한 줄 넣으면 되고, 없으면 시스템 글꼴로 보인다.

index.html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css" />

Tailwind 없이

순수 HTML·CSS 프로젝트는 sonia-ui/base.css 하나만 가져온다. 색 변수, 기본 모양, sn- 컴포넌트, 글자 클래스(sn-text-title)가 다 들어 있다. 모두 @layer sonia 안에 있어서 프로젝트가 직접 쓴 CSS가 항상 이긴다.

import "sonia-ui/base.css";

/* 또는 */
<link rel="stylesheet" href="node_modules/sonia-ui/src/css/base.css" />

변수만 필요하면 sonia-ui/themes.css.
