컴포넌트

버튼 · 카드 · 태그

모든 프로젝트가 같은 모양을 쓰도록 만든 클래스. 기존 .btn 등과 겹치지 않게 sn- 을 붙였다. Tailwind와 순수 CSS 둘 다 같은 이름.

ClassStyles
sn-btn버튼 기본 (모양 클래스와 함께)
sn-btn-primary주요 동작
sn-btn-soft보조 동작
sn-btn-outline취소 · 덜 중요한 동작
sn-btn-ghost툴바 · 아이콘 옆
sn-btn-sm / sn-btn-lg크기
sn-btn-pill알약 모양
sn-card떠 있는 면
sn-card-muted들어간 면
sn-tag태그 · 칩
sn-tag-muted회색 태그
sn-input입력창

예제

버튼

<button class="sn-btn sn-btn-primary">저장</button>
<button class="sn-btn sn-btn-soft">임시 저장</button>
<button class="sn-btn sn-btn-outline">취소</button>
<button class="sn-btn sn-btn-ghost">더 보기</button>
<button class="sn-btn sn-btn-primary" disabled>비활성</button>

크기 · 모양

<button class="sn-btn sn-btn-primary sn-btn-sm">작게</button>
<button class="sn-btn sn-btn-primary">보통</button>
<button class="sn-btn sn-btn-primary sn-btn-lg">크게</button>
<button class="sn-btn sn-btn-primary sn-btn-pill">알약</button>

카드

오늘의 불씨

12일째 이어지는 중

습관아침

들어간 면

입력 영역 · 인용 · 요약

<div class="sn-card">
  <p class="text-heading">오늘의 불씨</p>
  <p class="text-caption text-muted">12일째 이어지는 중</p>
  <span class="sn-tag">습관</span>
  <span class="sn-tag sn-tag-muted">아침</span>
</div>
<div class="sn-card sn-card-muted">...</div>

입력창

<input class="sn-input" placeholder="오늘 할 일" />

Tailwind 없이

sonia-ui/base.css를 가져오면 같은 클래스를 쓴다. 글자는 text-title 대신 sn-text-title.

<div class="sn-card">
  <h2 class="sn-text-heading">제목</h2>
  <button class="sn-btn sn-btn-primary">저장</button>
</div>
